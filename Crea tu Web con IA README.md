# 🌐 Crea tu Web con IA — Tutorial Profesional

> Tutorial educativo para aprender a construir páginas web profesionales usando **Claude AI** y **Visual Studio Code**, dirigido a principiantes y estudiantes del SENA.

🔗 **Ver tutorial en línea:** https://tutorial-web-ia.vercel.app/

---

## 📋 ¿Qué es este proyecto?

Un tutorial web completo e interactivo que enseña a crear páginas web desde cero usando Inteligencia Artificial como herramienta de apoyo. Cada módulo explica el **qué**, el **cómo** y el **por qué** de cada tecnología — no solo cómo copiar código.

Incluye advertencias reales sobre los **límites de la IA** y fuentes oficiales para verificar siempre lo que genera.

## ▶️ Cómo verlo localmente

1. Clona o descarga este repositorio
2. Abre la carpeta en **Visual Studio Code**
3. Instala la extensión **Live Server** (si no la tienes)
4. Haz clic derecho en `index.html` → **Open with Live Server**
5. Se abrirá en `http://127.0.0.1:5500`
